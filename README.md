# SummaBarcodeCreater
## :one: Что это такое

Данный плагин предназначен для добавления в документ CorelDraw штрихкодов и меток совмещения для плоттеров SummaCut. Процесс максимально автоматизирован: программа сама генериует номер штрихкода, находит контур резки по спотовому цвету, экспортирует готовый файл резки в формате plt. 
## :two: Как установить
Скачать архив, внутри будет папка "SummaBarcodeCreater" её нужно поместить по пути: **`C:\Program Files\Corel\CorelDRAW Graphics Suite\%Версия корела%\Programs64\Addons`**, затем перезагрузить корел, если он запущен. В верхнем меню должен появится новый элемент, как на скриншоте:

в выпадающем меню делаем командбар активным, должно быть примерно так:

> 
> :warning: **Нюансы первого запуска**
> 
> Из-за особенностей встраивания сторонних wpf в интерфейс корела могут немного скакать размеры кнопок командбара, особенно если масштабирование экрана в системе отличается от 100 процентов; также может быть неккоректная отрисовка кнопок, как правило ручное масштабирование командбара и последующее закрепление его на панели инструментов исправляет ситуацию, также из-за этой же проблемы может двоить кнопки на коммандбаре при закреплении, обычно достаточно скрыть командбар и затем снова его показать. В дальнейшем, если панель инструментов заблокирована, то нет никаких проблем с отрисовкой.
> 
> При первом запуске будет предупреждение об отсутствующем файле настроек, это нормально, программа создаст сама файл настроек и в дальнейшем все настройки будут сохранятся в него.
>


## :three: Как работает :point_right:
У плагина две кнопки  - одна при нажатии добавляет метки и баркоды к активной странице документа, центрирует содержимое и изменяет размер страницы с учётом содержимого и заданных отступов, экспортирует файл или файлы резки в указанную папку.

Вторая кнопка вызывает меню настроек плагина, немного о настройках:
- скорость резки задания, она записывается в файл;
- перерез задаёт значение overcut, оно также записывается в файл;
- опция добавления второго баркода, добавится второй баркод сверху документа, соответственно будут два файла резки;
- опция добавления имя документа сверху документа, надпись будет в кривых и на отдельном слое;
- создание файла превью для сервера резки ColorGate CutServer;
- выбор папки для экспорта файла резки;
- ввод имени спотового цвета, который используется для заливки абриса контура резки;
- отступы от меток до края страницы.
