# SummaBarcodeCreater
## :one: Что это такое

Данный плагин предназначен для добавления в документ CorelDraw штрихкодов и меток совмещения для плоттеров SummaCut. Процесс максимально автоматизирован: программа сама генериует номер штрихкода, находит контур резки по спотовому цвету, экспортирует готовый файл резки в формате plt. 
## :two: Как установить
Скачать архив, внутри будет папка "SummaBarcodeCreater" её нужно поместить по пути: **`C:\Program Files\Corel\CorelDRAW Graphics Suite\\%Версия корела%\Programs64\Addons`**, затем перезагрузить корел, если он запущен. В верхнем меню должен появится новый элемент, как на скриншоте:

> 
> :warning: **Нюансы первого запуска**
> 
> Из-за особенностей встраивания сторонних wpf в интерфейс корела могут немного скакать размеры кнопок командбара, особенно если масштабирование экрана в винде отлично от 100 процентов; также может быть неккоректная отрисовка кнопок, как правило ручное масштабирование командбара и последующее закрепление его в общем меню фиксит ситуацию, также из-за этой же проблемы может двоить кнопки на коммандбаре при закреплении, обычно достаточно скрыть командбар и затем снова его показать. В дальнейшем, если панель инструментов заблокирована, то нет никаких проблем с отрисовкой.
> 
> При первом запуске будет предупреждение об отсутствующем файле настроек, это нормально, программа создаст сама файл настроек и в дальнейшем все настройки будут сохранятся в него.
> 
## :three: Как работает :point_right:
У плагина две кнопки  - одна при нажатии добавляет метки и баркоды к активной странице документа, центрирует содержимое и изменяет размер страницы с учётом содержимого, с учётом заданных отступов, экспортирует файл или файлы резки в указанную папку; вторая кнопка вызывает меню настроек плагина, где есть опции выбора одного или двух баркодов, соответственно будет один или два файла резки; также есть возможность создать файл превью для сервера резки ColorGate CutServer. Также есть настройки, записываемые в файл резки: скорость, перерез кривой(офсет ножа), размытие кривой.
