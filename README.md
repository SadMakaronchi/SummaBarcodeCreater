# SummaBarcodeCreater
Данный плагин предназначен для добавления в документ CorelDraw штрихкодов меток свомещения для плоттеров SummaCut. Процесс максимально автоматизирован: программа сама генериует номер штрихкода, находит контур резки по спотовому цвету, экспортирует готовый файл резки в формате plt.
